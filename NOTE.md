# Perbedaan App Router dan Pages Router

Pages Router (folder `pages/`) memetakan tiap file langsung jadi rute, data fetching pakai `getServerSideProps`/`getStaticProps`, dan semua komponen otomatis dirender di client kecuali fungsi fetching tersebut. App Router (folder `app/`) memakai konvensi berkas seperti `page.tsx`, `layout.tsx`, `loading.tsx`, `error.tsx` per segmen, dan berbasis React Server Components — komponen default dirender di server, sehingga JavaScript yang dikirim ke browser lebih kecil. App Router juga mendukung nested layout yang persist antar navigasi (tidak re-render sidebar), streaming dengan Suspense, dan Server Actions untuk mutasi data tanpa perlu membuat API Route terpisah. Route groups `(nama)` memungkinkan pengelompokan tanpa memengaruhi URL. Singkatnya, App Router lebih fleksibel dan performan untuk aplikasi kompleks, tapi punya kurva belajar lebih tinggi karena konsep server/client boundary yang baru dibanding Pages Router yang lebih sederhana dan konvensional.
